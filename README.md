## Featured Labs

### Wazuh SIEM Detection Lab
Real-time threat detection with a Wazuh SIEM: two operating systems monitored on Docker, attacks fired from a Kali box (SSH brute force, PowerShell abuse, file tampering), and a custom correlation rule I wrote to catch a full attack chain. Every detection mapped to MITRE ATT&CK.
[View repository](https://github.com/Maxi414/wazuh-siem-detection-lab)

### Phishing Simulation Lab: GoPhish, OSINT & Credential Harvesting
End-to-end phishing campaign built from scratch: a GoPhish server hidden behind an Nginx reverse proxy (TLS + stripped fingerprint headers), passive OSINT with theHarvester, and a credential-harvesting landing page. Run entirely against a fictional organization and test mailboxes in a fully contained lab, with social-engineering analysis and blue-team mitigations (MFA, DMARC/SPF/DKIM).
[View repository](https://github.com/Maxi414/gophish-phishing-simulation-lab)

### Cloud Security Lab: AWS IAM, S3 & CloudTrail Hardening
Hardening of a clean AWS account across identity, data protection and audit logging. Provisioned with Terraform, validated with the AWS CLI, tested with simulated attacks and scanned with Checkov in GitHub Actions.
[View repository](https://github.com/Maxi414/aws-iam-s3-cloudtrail-hardening)

### Linux Hardening Lab: OS Bunker
Defensive hardening of a Linux server focused on reducing attack surface, securing services, auditing and integrity monitoring, with every hardening decision documented and justified.
[View repository](https://github.com/Maxi414/linux-hardening-lab)

### Network Audit Lab
Network vulnerability assessment using Kali Linux, Nmap and Nessus against Metasploitable 2 in an isolated VirtualBox environment. Includes enumeration, vulnerability correlation and remediation recommendations.
[View repository](https://github.com/Maxi414/network-audit-lab)
